# تشغيل بحث عناوين حماة

يعتمد البحث النصي في جربوع على طلب يدوي من المستخدم فقط، ثم يمر عبر الخادم مع تخزين مؤقت وحد أدنى يزيد على ثانية واحدة بين الطلبات غير المخزنة. لا يُنفّذ إكمال تلقائي أثناء الكتابة، وتُقيَّد النتائج جغرافياً داخل حماة قبل إعادتها للتطبيق.

تستند هذه القيود إلى سياسة استخدام Nominatim: حد أقصى طلب واحد في الثانية، معرّف تطبيق واضح، وإتاحة تبديل الخدمة وتخزين النتائج مؤقتاً.
