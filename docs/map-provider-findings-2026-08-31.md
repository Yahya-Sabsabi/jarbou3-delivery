# نتائج بحث مزودي الخرائط — 2026-08-31

## Google Maps Platform

المصدر الرسمي: https://developers.google.com/maps/billing-and-pricing/pricing

وفق قائمة Google العالمية المحدثة في 2026-08-31، تُحسب خدمات Maps وRoutes وPlaces بحسب SKU وعدد الأحداث القابلة للفوترة شهرياً. الأمثلة الحالية: Maps SDK له استخدام مجاني غير محدود ضمن جدول Maps؛ Dynamic Maps له حد مجاني شهري 10,000 تحميل ثم 7 دولارات لكل 1,000 تحميل؛ Routes Compute Essentials له حد مجاني 10,000 طلب ثم 5 دولارات لكل 1,000؛ Places Autocomplete له حد مجاني 10,000 طلب ثم 2.83 دولار لكل 1,000؛ Geocoding له حد مجاني 10,000 ثم 5 دولارات لكل 1,000؛ وGoogle Geolocation له حد مجاني 10,000 ثم 5 دولارات لكل 1,000. لا يعني ذلك أن المنصة مجانية أو غير محدودة بالكامل، كما يلزم تفعيل Billing ومراقبة الحصص.

المصدر الرسمي: https://developers.google.com/maps/billing-and-pricing/overview

استبدلت Google الائتمان الشهري القديم البالغ 200 دولار بحدود مجانية لكل SKU منذ مارس 2025. توجد أيضاً اشتراكات ثابتة تبدأ من 100 دولار شهرياً لـ50,000 مكالمة، لكن الاستخدام خارج النطاق أو بعد الحدود يخضع للفوترة.

المصدر الرسمي: https://developers.google.com/maps/documentation/places/web-service/usage-and-billing

تتطلب Places API مفتاحاً أو OAuth وBilling. يساعد Field Mask في تقليل البيانات والفوترة، وتوجد حصص لكل طريقة. عند بلوغ quota قد تتوقف الاستجابة، لذلك يجب ضبط تنبيهات وميزانيات وحصص.

## OpenStreetMap وMapLibre

المصدر الرسمي: https://maplibre.org/

MapLibre مكتبة مفتوحة المصدر للويب والهاتف لعرض الخرائط، لكنها ليست مزوداً مستقلاً للبيانات أو البلاطات. يمكن استخدام MapLibre مع بيانات OpenStreetMap أو بلاطات مستضافة ذاتياً.

المصدر الرسمي: https://operations.osmfoundation.org/policies/tiles/

بيانات OpenStreetMap مجانية، لكن خوادم البلاطات العامة ممولة بالتبرعات وقدرتها محدودة ولا تقدم SLA. يلزم إظهار attribution، احترام التخزين المؤقت، وعدم الاستخدام الثقيل أو التنزيل المسبق أو الاستخدام غير المتصل. قد تُحجب الاستخدامات المخالفة دون إشعار. لتطبيق تجاري، البديل هو مزود OSM مشتق أو الاستضافة الذاتية.

المصدر الرسمي: https://openmaptiles.org/docs/

OpenMapTiles يتيح إنشاء واستضافة بلاطات متجهة خاصة مع الالتزام بترخيص ODbL وذكر OpenStreetMap وOpenMapTiles. وثائق البدء توصي بـLinux x86_64 ومساحة أكبر من 15GB وذاكرة أكبر من 3GB للتجهيز، إضافة إلى Docker.

## الخلاصة الفنية

GPS الذي يقرأه الهاتف عبر Expo Location لا يفرض رسوم Google لكل قراءة. يمكن جعل MapLibre أو Leaflet وGPS وRealtime داخل جربوع بلا رسوم API لكل حركة، لكن الاستضافة والإنترنت والتخزين ليست مجانية بالضرورة. الحل القابل للاستبدال هو فصل واجهة الخريطة ومصدر البلاطات والبحث والتوجيه خلف محولات مستقلة، مع حفظ «أماكن جربوع» في قاعدة البيانات الخاصة ليتولى المدير إضافة الاسم والإحداثيات فقط.
