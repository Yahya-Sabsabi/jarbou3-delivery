# عقد المصادقة المحمي — OPTIMUS X

هذا المستند يحدد المسار العامل الذي يجب اعتباره واجهة مستقرة قبل أي تعديل هيكلي في OPTIMUS X. أي تغيير في هذا المسار يجب أن يسبقه اختبار regression، ثم تشغيل الاختبارات وبناء نسخة Android قبل دمجه.

## النطاق

ينطبق العقد على العميل والسفير معاً. يشمل إنشاء الحساب، تسجيل الدخول، استعادة الجلسة، وتحديد عنوان API الذي تُرسل إليه الطلبات. لا يجوز تغيير هذا المسار أثناء تعديل الواجهات أو إضافة المزايا إلا مع الحفاظ على نفس العقد الخارجي.

## رقم الهاتف

تدخل أرقام سوريا بصيغة محلية مثل `09xxxxxxxx` أو بصيغة دولية مثل `+9639xxxxxxxx`. يجب أن تمر جميع الصيغ عبر `normalizeJarbou3Phone` قبل إنشاء البريد canonical أو إرسال طلب المصادقة. الصيغة النهائية المعتمدة هي رقم دولي يبدأ بـ `+963`، وتستخدم المقارنة الموحدة لمنع الحسابات المكررة.

## تسجيل الدخول

يستخدم العميل والسفير route المصادقة المشترك في الخادم. يرسل التطبيق الرقم المطبع وكلمة المرور إلى الخادم عبر tRPC، ويقرأ الخادم هوية Supabase Auth أولاً ثم يسترجع الملف الشخصي المطابق للدور والحالة. يجب ألا تعيد الواجهة شرط إنشاء كلمة مرور جديدة إلى مسار الدخول؛ الحسابات القديمة قد تملك كلمات مرور أقصر من الحد المفروض على كلمات المرور الجديدة.

بعد نجاح المصادقة، يحفظ التطبيق رمز الجلسة في طبقة الجلسة الحالية، ثم يسمح باستعادة مساحة العمل. لا يجوز تغيير مفتاح التخزين أو ترتيب استعادة الجلسة أو تحويل APK المستقل إلى عنوان معاينة مؤقت.

## إنشاء الحساب

يحافظ مسار إنشاء حساب العميل والسفير على التحقق الحالي من الاسم والرقم وكلمة المرور والموافقة، ويستخدم route التسجيل الحالي وطلب التحقق عند الحاجة. يجب أن تبقى رسائل أخطاء tRPC المرمزة ظاهرة للمستخدم برسالة مفهومة، وألا تتحول إلى رسالة عامة مثل `Service Unavailable`.

## عنوان API

في APK المستقل يستخدم التطبيق عنوان API المنشور المضمّن في `app.config.ts` عبر `extra.apiBaseUrl`. يسمح Expo Go بعنوان المعاينة المقابل فقط عندما تكون بيئة التشغيل Expo Go فعلياً. لا يجوز إدخال عنوان Metro أو عنوان معاينة مؤقت داخل APK Release.

## قواعد التغيير المستقبلية

قبل تغيير `shared/jarbou3-phone.ts` أو `components/jarbou3-app.tsx` في مسار الدخول والتسجيل أو `server/routers.ts` في routes المصادقة أو `lib/trpc.ts` و`constants/oauth.ts` في اختيار عنوان API، يجب تحديث اختبارات العقد وتشغيلها. يجب اختبار العميل والسفير، الصيغتين المحلية والدولية، الحسابات القديمة، رسائل الخطأ، واستعادة الجلسة.

> **قاعدة محمية:** الواجهات الجديدة يمكن أن تتغير، لكن عقد المصادقة لا يتغير دون اختبار وإصدار قابل للاسترجاع.
