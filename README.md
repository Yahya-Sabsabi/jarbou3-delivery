# جربوع للتوصيل

> نظام توصيل محلي لحماة يضم تطبيقاً واحداً بأدوار **العميل** و**السفير**، وبوابة إدارة ويب مستقلة على المسار `/admin`.

## 1. الغرض ونطاق المشروع

يخدم جربوع دورة طلب التوصيل كاملة: التسجيل الآمن، التحقق عبر WhatsApp، إدارة السفير، إنشاء الطلب، عرضه تدريجياً على السفراء الأقرب، متابعة السفير على الخريطة، إثبات التسليم، والرقابة من بوابة الإدارة. لا يحتوي هذا المستودع على تسجيلات مكالمات أو تكامل Telegram؛ فهما خارج نطاق المشروع الحالي.

## 2. البنية التقنية

| الطبقة | التقنية | المسؤولية |
|---|---|---|
| تطبيق الهاتف | Expo 54، React Native، TypeScript | تجربة العميل والسفير، GPS، الكاميرا، الإشعارات، والتخزين الآمن للجلسة |
| واجهة الويب الإدارية | HTML/CSS/JavaScript ضمن `admin-site/` | إدارة الحسابات والخصومات والأرشفة والتقارير وإعدادات الإصدار |
| الخادم | Express وtRPC ضمن `server/` | التحقق من الأدوار، قواعد الطلبات، جلسة الإدارة، التصدير، والملفات |
| البيانات | Supabase Postgres وAuth وStorage | الحسابات والطلبات والوثائق والمواقع الحية والأرشيف |
| التحديث الحي | WebSocket bridge ضمن `server/jarbou3-realtime-bridge.ts` | حالة الطلب وموقع السفير للعميل |

## 4. البدء السريع للمطور

يتطلب المشروع Node.js 22 وpnpm 9. لا تنشئ أو تنسخ ملف بيئة إنتاجي إلى المستودع.

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm dev
```

يبدأ `pnpm dev` خادم Express على المنفذ `3000` ومعاينة Expo على المنفذ `8081`. عند تعديل قاعدة البيانات، يضاف ملف SQL جديد غير قابل للتغيير في `supabase/migrations/` ويطبق على المشروع الصحيح ثم يوثق في سجل التغيير.

## 5. معايير الجودة قبل أي تغيير

1. راجع `todo-ezmlh0n7.md` وسجّل المهمة قبل التنفيذ.
2. لا تكشف أي مفتاح أو رمز أو كلمة مرور في الكود أو الاختبارات أو السجل.
3. نفّذ `pnpm check && pnpm test && pnpm build` قبل الحفظ.
4. اختبر التغييرات الحساسة في الخادم باستخدام بيانات غير تشغيلية فقط.
5. أنشئ checkpoint قبل التسليم أو أي تعديل واسع.

## 6. التشغيل والنسخ الاحتياطي

يحتوي هذا المستودع على **الشفرة والترحيلات والوثائق فقط**. لا تحفظ داخله بيانات العملاء أو الوثائق أو صور الهوية أو مواقع GPS أو ملفات البيئة. تفاصيل الاسترداد والتشغيل الأمني موجودة في [دليل الاستمرارية](docs/CONTINUITY_GUIDE.md) و[سياسة الأمان](SECURITY.md).
